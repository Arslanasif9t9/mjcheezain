## Notes / gotchas
- Admin login **username** field se hota hai — email wahan likhein.
- Purana admin `admin`/`admin123` live par bhi hoga — pehli login par password khud hash ho jayega, lekin password weak hai; change/delete recommended.
- Purani product videos (jo pehle upload huin) live par ghalat extension (.jpeg) se stored hain — wo edit-page par play nahi hongi. Naye uploads theek hain. Chaho to affected products ki video dobara upload kar dena (ya baad mein hum server repair script chala denge).
- View cache: kuch bhi nahi karna — compiled views file-change par khud refresh hoti hain.
