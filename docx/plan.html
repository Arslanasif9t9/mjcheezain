4 Persistent History — localStorage (No Database!)

💾 Browser localStorage — max 70 messages

Owner decision: database mein koi change nahi — na migrations, na tables. Poori history browser ke localStorage mein.

KeyValue
mj_guide_historyJSON array: { role, text, t }
  • Har send/reply ke baad dono messages append hote hain.
  • Array > 70 → sab se purane messages trim (newest 70 hamesha safe).
  • Corrupt JSON → silently fresh chat (widget kabhi crash nahi).

Old chat ki yaad & loading

  • Widget open → localStorage se poori history render — refresh/close par kuch delete nahi hota.
  • AI ko purani baat yaad rehti hai: har request ke sath last 10 messages context ke taur par jate hain.
  • Guest / customer / vendor sab ke liye same — na login, na cookie, na user_id.
  • Server bilkul stateless — chat ka kuch bhi server par save nahi hota.
  • Trade-off (accepted): history per-browser/per-device hai; browser data clear karne par chat bhi clear.

New backend files

MjGuideController · Services/MjGuide/ChatService · GeminiProvider · GrokProvider · knowledge.md · config in services.php + .env keys — 0 migrations
